# tgbot

Telegram-бот для группового чата с множеством функций: дни рождения, мемы, погода, игры и списки задач.

## Возможности

### 🎂 Дни рождения
- Сохрани свой ДР: `/birthday set DD.MM`
- Добавь ДР другого пользователя: `/birthday add @тег DD.MM` или `/birthday add Имя DD.MM`
- В полночь бот отправляет поздравление — случайный шаблон с тегом (для Telegram-пользователей) или простое сообщение «Сегодня день рождения Имя» (для внешних)
- Каждый чат хранит свой список независимо

### 😂 Лучшие мемы
- Бот отслеживает все фото и видео в чате
- Реакции накапливаются в реальном времени
- Каждые 3 часа оценивает посты: топ 20% по реакциям пересылается в настроенный канал
- Канал настраивается отдельно для каждого чата

### 🌤 Погода
- Список городов для каждого чата, вывод одной командой `/weather`
- Сортировка от тёплых к холодным
- Показывает температуру, ощущаемую, влажность и УФ-индекс

### 🎲 Случайный выбор
- `/random вариант1 вариант2 вариант3` — выбирает один из вариантов

### 📏 Игра в см (`/dicky`)
- Каждый пользователь хранит своё значение в «см» (отдельно для каждого чата)
- `/dicky roll` — бросить кубик раз в 8 часов (прибавляет от 1 до 15 см)
- `/dicky raise <сумма>` — бросить вызов другим игрокам на ставку
- `/dicky top` — таблица лидеров чата
- `/dicky config` — настройки таймеров (только для админов)

### 🌈 Насколько ты гей
- `/how_many_im_gay` — случайный процент на сегодня (один раз в день, единый для всех чатов)
- Кнопка «Поделиться» для отправки результата в другой чат

### ✅ Список задач (`/todo`)
- Личные списки задач, отдельные для каждого чата
- Несколько списков с возможностью переключения
- Добавление задач через запятую: `задача1, задача2, задача3`
- Отметка выполненных и удаление прямо из сообщения

## Команды

### 🎂 Дни рождения
| Команда | Описание |
|---|---|
| `/birthday set DD.MM` | Сохранить свой день рождения |
| `/birthday add @тег DD.MM` | Добавить ДР по Telegram-тегу |
| `/birthday add Имя DD.MM` | Добавить ДР по имени |
| `/birthday list` | Список всех ДР в чате |
| `/birthday delete` | Удалить свой ДР |
| `/birthday delete @тег` | Удалить чужой ДР |
| `/birthday test` | Тестовое поздравление |

### 🌤 Погода
| Команда | Описание |
|---|---|
| `/weather` | Показать погоду для всех городов |
| `/weather add <город>` | Добавить город |
| `/weather remove <город> [город2...]` | Удалить город(а) |
| `/weather list` | Список городов |

### 📏 Игра в см
| Команда | Описание |
|---|---|
| `/dicky` | Твой текущий размер |
| `/dicky roll` | Бросить кубик (раз в 8 ч) |
| `/dicky raise <сумма>` | Бросить вызов на ставку |
| `/dicky top` | Таблица лидеров |
| `/dicky config` | Настройки (только админы) |

### Прочие
| Команда | Описание |
|---|---|
| `/random вар1 вар2 ...` | Случайный выбор |
| `/how_many_im_gay` | Насколько ты гей сегодня |
| `/todo` | Список задач |
| `/setmemechannel @channel` | Установить канал для мемов (админ) |

## Установка и запуск

### 1. Создай бота
Зарегистрируй бота у [@BotFather](https://t.me/BotFather) и получи токен.

Включи в BotFather:
- **Group Privacy → Turn off** (чтобы бот видел все сообщения в группе)
- **Inline Mode → Turn on** (для кнопки «Поделиться» в `/how_many_im_gay`)

Добавь бота в группу как **администратора** (для получения реакций).

### 2. Настрой .env
```bash
cp .env.example .env
```
```
BOT_TOKEN=токен_от_BotFather
DATABASE_PATH=bot.db
TIMEZONE=Europe/Moscow
LOG_FILE=bot.log
```

### 3. Установи зависимости
На macOS:
```bash
SDKROOT=$(xcrun --show-sdk-path) npm install
```
На Linux:
```bash
npm install
```

### 4. Запусти
```bash
# Разработка (авто-перезапуск)
npm run dev

# Продакшн
npm run build && npm start
```

## Настройка мем-канала

1. Создай канал в Telegram
2. Добавь бота в канал как **администратора** с правом публикации
3. В групповом чате:
   ```
   /setmemechannel @твой_канал
   ```
